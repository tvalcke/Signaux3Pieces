# Projet Signaux III - Reconnaissance de pièces TWD

## Description

Projet réalisé dans le cadre du cours de Signaux III : Traitement numérique à l'EPHEC (2026-2027).

L'objectif est de développer un programme permettant de reconnaître et d'identifier différentes pièces de monnaie taïwanaises (TWD) à partir de photographies, en utilisant des techniques de traitement numérique d'images.

Les photographies seront prises dans des conditions contrôlées (éclairage, distance et arrière-plan fixes) afin de faciliter leur analyse dans un premier temps.

## Objectifs

- Constituer un jeu de données de photographies de pièces TWD.
- Prétraiter les images pour faciliter leur analyse.
- Détecter et isoler les pièces sur les images.
- Extraire des caractéristiques permettant de différencier les pièces (taille, couleur, contours, etc.).
- Développer un algorithme capable d'identifier la valeur des pièces.
- Tester le programme et évaluer sa précision.

## Technologies envisagées

- Python
- OpenCV
- NumPy
- Matplotlib

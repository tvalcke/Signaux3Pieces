# Méthodologie

Ce document présente les principales étapes prévues pour le projet.

## 1. Acquisition

Collecter des photographies de pièces TWD dans des conditions d'acquisition contrôlées.

## 2. Prétraitement

Normaliser la qualité des images, réduire le bruit et préparer les données pour l'analyse.

## 3. Détection

Localiser les pièces sur l'image et isoler les régions d'intérêt.

## 4. Extraction de caractéristiques

Calculer des descripteurs tels que la taille, les contours, les statistiques de couleur et les informations de forme.

## 5. Classification

Utiliser les caractéristiques extraites pour attribuer à chaque pièce la bonne valeur nominale.

## 6. Validation

Évaluer les performances du système sur des images de test et documenter les résultats.

## Résultat attendu

Le projet vise à construire un pipeline simple et maintenable pour reconnaître des pièces TWD à partir de photographies acquises dans des conditions contrôlées.

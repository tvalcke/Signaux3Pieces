# Protocole d'acquisition

Ce document décrit les conditions à respecter pour capturer les photographies des pièces TWD.

## Objectifs

- Standardiser les conditions d'éclairage ( 1ere version puis on avisera)
- Garder un arrière-plan propre et reproductible ( style fond uni)

## Configuration proposée

- Utiliser une table pour l'acquisition.
- Placer les pièces sur fond neutre.
- Contrôler la source lumineuse pour éviter les ombres et les reflets.
- Capturer plusieurs images par pièce afin de renforcer la robustesse et différents montant à la fois
- Enregistrer les images brutes dans le dossier `data/raw/`
